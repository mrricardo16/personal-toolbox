# 工作报告起草

围绕报告对象和实际目标，突出事实、过程和分析之间的联系。篇章应当帮助读者理解现状和重点，不按固定模板强制安排章节。

- 先说明报告的范围、当前状态及关键问题，资料缺失时用待核实标记而非补造背景。
- 将“做了什么、怎样做、有什么结果、还存在哪些限制”写清楚。保留确切项目名、技术或业务术语、统计周期。
- 分析性判断应由明确事实支撑；不把相关性表述为原因，不把个别案例扩大成整体结论。
- 避免同一事实在摘要、正文和结尾中反复用不同空话叙述。
- 优先使用自然的企业办公语言；只有用户要求时才采用机关公文惯用表述。
- 需要数据表时提供可核对的表格；不构造不存在的指标。
