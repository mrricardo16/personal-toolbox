# AI 文档助手 V2 — 实施与验收

- [x] ASP.NET Core API 与 Vue3 页面，旧版 index.html 原样保留
- [x] 原 13 种技能与 Prompt 自动提取，初稿及忠实审校
- [x] JSON / 临时 / 本机持久化 API Key
- [x] Windows 自包含 ZIP 打包脚本、CI 和启动健康检查

## P1 DOCX 常规写作

- [x] DOCX 正文和表格解析、批量上传、逐文件选择事实/风格用途
- [x] 文档月份可修改，文件与手工材料组合写作
- [ ] 复杂表格合并单元格、图片识别、超长文件自动分片（不在本轮目标内）

## P2 年度 / 多月总结

- [x] 逐篇 AI 抽取工作事项、进度、指标及精确来源摘录
- [x] 跨月语义归并：持续项目、周期性任务、重复成果、独立事项
- [x] 关键冲突或原文摘录不匹配需人工确认；一般疑问可标注后继续
- [x] 可查看来源、编辑归并台账、选择排除事项、直接或审核后生成
- [ ] 用真实 6～15 篇月报完成数据准确性评测（需真实授权测试材料和 API Key）

## P3 Word 导出

- [x] 导出可编辑 DOCX；默认样式、标题、表格
- [x] 自动推荐、手动选择参考模板，提取样式、页面及常见表格样式
- [x] 安全复制：生成新文档，默认不复制旧正文、批注、修订记录
- [x] 页眉页脚保留属于用户显式选择，避免继承过期内容
- [ ] 复杂图文混排、浮动图表、精确分页（超出本轮范围）
- [ ] 用户提供的实际单位 Word 模板在 Word/WPS 中人工视觉验收

## P4 质量和交付

- [x] 自动单元测试：Word 生成、模板旧正文隔离、DOCX 解析、事实来源与归并兜底
- [x] GitHub Actions：后端单元测试、Vue 构建、.NET 自包含发布、启动冒烟
- [ ] 真实 DeepSeek 模型完整写作和费用/耗时测试（未提供密钥，不会代替用户消费）
- [ ] 外部网络/公网服务部署（需用户目标环境和 HTTPS / 认证配置）
- [ ] 高级并发控制、审计日志与多人账户（非本轮单用户范围）

## 验收规则

测试分为“自动测试通过”和“真实业务数据验收”两类，不能混为一谈。构建成功只表明程序可编译、发布与启动，不证明 LLM 总结正确或任意 Word 模板完全还原。
