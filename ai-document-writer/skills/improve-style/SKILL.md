# 中文写作表达优化

目标是提高信息密度、连贯性和可读性，不是简单把文章改成口语，也不追求“绕过 AI 检测”。

- 优先用具体的工作对象、实际动作和证据替换缺乏信息的形容词。
- 避免连续段落完全相同的句式与转折；必要的公文规范表达应保留。
- 对无实质信息的“持续加强、全面推动、取得显著成效”等句式，若材料没有证据则删去或改为中性描述。
- 保持语体与文种匹配：企业工作总结通常比机关通知更自然；会议纪要不能擅自引入报告式评述。
- 不改变事实、数字、阶段状态、专有名词或用户明确要求的篇章结构。
- 按用户明确要求调整细节密度。需要简洁时保留重点及必要事实，需要详细时扩展有证据的做法，并保留用户指定的重点。
