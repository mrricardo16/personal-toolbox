# AI 文档助手｜当前进度与交付评估

> 截至 **2026-11-17**；发行包 **0.3.0**；新版页面 **V2.2**。记录依据：`main` 的自动构建及仓库现有代码，后续更新应同步校验。

## 结论

**可以交付：Windows x64 便携试用包、Linux x64 自包含服务器包、完整源码与部署说明。**

**暂不宜宣称：真实业务已验收、面向公众安全运营、任意 Word 模板高保真复刻。** 这些仍需业务测试或进一步工程建设。

## 一、已完成的工程能力

| 功能 | 代码状态 | 证据及约束 |
| --- | --- | --- |
| 原有单文件版本保持可回退 | 已保留 | `ai-document-writer/index.html` 原文件不变，新版构建为 `/legacy.html` |
| Vue3 + ASP.NET Core 后端 | 已实现 | 前后端统一发布；后端调用 DeepSeek |
| 13 类文书技能、两阶段审校 | 已迁移 | 构建阶段从旧版提取 Prompt 规则；真实输出需人工核实 |
| JSON / 临时 / 本机持久化 Key | 已实现 | 服务器模式禁止网页持久化全局 Key |
| DOCX 多文件读取及用途选择 | 已实现 | 正文/表格/标题层级；无图片 OCR |
| 年度多月总结、来源追溯及去重 | 已实现 | 可人工查看/编辑；真实复杂材料的准确性未验证 |

| Linux-x64 服务器 ZIP | 自动构建通过 | 不等于已经部署公网服务 |

## V0.3.0 写作体验增强（实验性）

- 7 项重新编写、白名单加载的本地写作/审校/改稿 Skill；传统 13 类 Prompt 仍然可选。
- 新增“继续修改当前稿件”接口：局部修订由程序保证不改选区外内容；候选稿不自动覆盖原稿。
- 版本快照可恢复、比较、导出 JSON；默认只存页面内存，不自动永久保存业务文本。
- 年度总结先组织写作提纲，再利用归并事实及来源上下文写正文。
- 新增 20 个虚构业务评测案例及两次模型调用的 A/B 入口。评测素材与人工评分规范见 [WRITING_EVAL.md](WRITING_EVAL.md)。

**新功能已经通过模拟模型和自动构建检查，但真实模型文风质量、修改准确性、人工盲评结果未验收。**

## 四、推荐交付定义

- **个人自用或内部试用**：可交付，建议使用已打包的 Windows 版本进行真实手工体验。
- **真实业务试运行**：先使用脱敏授权材料完成 P0 业务验收，保留人工复核步骤。
- **正式生产 / 公网 SaaS**：当前不能直接交付；必须补身份认证、密钥隔离、限流、日志策略和真实业务验收。

## 五、建议的下一步

第一步：在 Windows 便携版输入个人 Key，用一份简短材料完成生成与审校测试。第二步：提供至少 6 篇脱敏月报，人工记录真实事实与模型归并差异。第三步：使用真实 Word 模板检验排版，再针对发现的问题修复。执行与记录格式见 [ACCEPTANCE.md](ACCEPTANCE.md)。
