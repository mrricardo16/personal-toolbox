# AI 文档助手

基于 DeepSeek API 的单文件文档生成工具，适合直接在浏览器中运行。

## 功能

- 基于 DeepSeek API
- 支持文档技能切换
- 支持正式材料生成
- 支持专有名词保护
- 支持自动审校
- 支持复制结果和下载 Markdown、TXT 文件

## 使用方式

1. 用浏览器打开 [`index.html`](index.html)。
2. 输入自己的 DeepSeek API Key。
3. 选择文档类型，并输入事实材料、任务要求及其他信息。
4. 点击“生成文档”。

API Key 只在当前页面运行期间保存在内存中，不写入浏览器本地存储或会话存储。

## 注意事项

- 不要上传自己的 API Key。
- 不要上传涉密资料。
- 不要输入不允许发送至外部服务的内部材料。
- API 费用由使用者自行承担。
- 浏览器会将输入内容直接发送到 DeepSeek API，请确认网络和数据合规要求后再使用。
- 双击打开时，部分浏览器可能限制剪贴板等能力；生成和下载功能不受该限制影响。

## 更新记录

### 2026-08-10

修复“初稿生成后几秒自动消失”的问题。

此前开启“自动忠实审校”后，系统会在初稿生成完成后继续进行第二次审校请求。如果审校接口返回空内容、请求失败或被中止，可能导致已经生成的初稿被覆盖。

本次调整后：

- 初稿生成成功后立即保留在页面中。
- 自动审校返回空内容时，不再覆盖初稿。
- 自动审校请求失败时，保留初稿。
- 审校过程中手动停止时，保留初稿。
- 只有审校成功返回有效内容时，才使用审校稿替换初稿。
- 初稿生成后明确提示可立即复制或下载。
