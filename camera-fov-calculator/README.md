# 工业场景相机可照范围计算器

用于计算工业场景下相机的可照范围，以及在给定货位尺寸、间隔和误差余量条件下可照货位数量。

## 功能

- 根据相机高度和水平、垂直视场角计算可照范围。
- 支持输入货位或托盘长度、宽度和间隔。
- 支持按每边误差余量扣除有效范围。
- 自动比较货位不同摆放方向，计算可照货位数量。
- 绘制货位布局示意图。
- 纯 HTML、CSS 和 JavaScript，无需安装依赖。

## 使用方式

1. 用浏览器打开 [`index.html`](index.html)。
2. 输入相机高度、水平视场角和垂直视场角。
3. 输入货位尺寸、货位间隔和长宽方向误差余量。
4. 点击“确定计算”查看可照范围、货位数量和布局。

## 计算说明

视场范围依据相机高度和视场角计算；货位数量会扣除两侧误差余量，并分别计算普通方向与旋转 90 度方向，取可容纳数量较大的结果。

## 注意事项

- 本工具适合方案估算和现场辅助计算，实际安装仍需结合镜头、分辨率、安装角度、遮挡和现场安全余量确认。
- 工具不上传数据，也不调用外部 API。
