- [ ] **风格隔离**：上传旧版格式文件并标记“仅参考风格”，确认最终事实不引入往年项目或业绩。

## 3. 推荐的业务通过标准

- 关键工作成果及数字必须能回溯到对应来源；来源不明时必须保留“需核实”或排除。
- 同一事项的阶段进展可归并，但独立周期工作不得因文字相似而误删。
- 不得把不同月份的累计指标、百分比直接相加；统计口径不明确时应由用户确认。
- 关键冲突不能未经确认就形成确定性结论。
- Word 结果应为可编辑 DOCX，主要版式符合选定模板；**不要求任意复杂文档像素级复刻**。
- 在错误和取消场景，用户应能了解原因并继续操作；不应泄露真实 API Key。
