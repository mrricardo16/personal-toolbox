# AI 文档助手｜开发路线与验收台账

> 更新于 2026-11-17；程序包 0.2.0（界面 V2.1）。标记 `[x]` 表示已有代码及相应自动化检查，**不代表真实业务效果已经验收**。

## P0 — 新架构与原功能兼容

- [x] Vue3 + ASP.NET Core (.NET 10) 基础工程，保留旧 `index.html`。
- [x] 从旧版提取 13 类技能规则，保留事实约束、保护项、初稿和二次审校。
- [x] 后端 JSON、临时与桌面本机持久化 API Key；服务器模式禁用网页持久化全局 Key。
- [x] Windows 自包含 ZIP，双击 EXE 启动本机网页。
- [ ] 人工对照原版逐项完成真实模型回归（Prompt 兼容、生成、审校及错误处理）。

## P1 — DOCX 多材料参考写作

- [x] 多文件上传、DOCX 正文和表格解析、常见标题层级抽取。
- [x] 文件用途：仅事实、仅风格、事实与风格两者兼用；支持批量设置。
- [x] 文件指定所属月份，与手动事实材料组合。
- [x] 前端规则测试验证仅风格参考文档不参加年度事实提取。
- [ ] 用多种真实 DOCX（表格、合并单元格、空文档、损坏文件、超大文件）做人工兼容性检查。

## P2 — 年度/多月总结

- [x] 逐篇事实提取：名称、阶段、数据、原文摘录及来源文件。
- [x] 单篇最多 150,000 字符，按段分片提取；单篇最多 120 项事实，整体台账最多 250 项。
- [x] 同一工作跨月进度归并、重复成果与周期性数据区分。
- [x] 关键冲突需人工确认或排除，一般疑问在正文末尾保留核验提示。
- [x] 台账可查看、修改后生成；支持保留初稿与自动忠实审校。
- [x] 6 篇合成月报的 HTTP 端到端流程验证（固定模拟模型响应）。
- [ ] 用真实 6–15 篇月报评价漏提率、误归并、冲突识别、统计口径和模型费用。
- [ ] 超过单次模型 Prompt 容量的超大型台账自动分层归并（目前不支持）。

## P3 — Word 排版和导出

- [x] 输出可编辑 DOCX，提供默认排版和模板自动推荐/手动指定。
- [x] 复用常用 Word 样式、表格样式、页面设置；可选保留页眉页脚。
- [x] 新建 DOCX 输出，避免直接复制旧正文、批注、修订记录。
- [x] 自动测试验证生成文档的内容、模板旧事实隔离和常见版式结构。
- [ ] 使用真实单位模板在 Microsoft Word 与 WPS 中目视检查。
- [ ] 复杂图文混排、浮动对象、精确分页（不在当前交付范围内）。

## P4 — 测试、发布与安全

- [x] 前端 Node 测试、后端 xUnit 测试、HTTP 模拟模型集成测试。
- [x] Windows/Linux 自包含包 GitHub Actions 构建和启动冒烟。
- [x] 桌面服务只监听本机并验证 Host/Origin；Key 持久化权限检查。
- [x] 交付文档、部署说明、业务验收模板与风险记录。
- [ ] 真实 API Key 调用和 Token 费用/时延记录。
- [ ] Windows 桌面实际用户操作测试：启动、关闭、Key 保存、上传、取消、导出。
- [ ] Linux/Windows 服务器真实部署环境、身份认证、HTTPS、限流、日志与监控。
- [ ] 多用户认证、租户隔离、云端历史与审计日志（独立需求，未实现）。
